# Project naming

Recommendation: **Kmpwright** (repository and artifacts: `kmpwright`; Kotlin API: `KmpwrightConfig`).

| Name | Assessment |
| --- | --- |
| Kmpwright | Best fit: signals Kotlin Multiplatform and a Playwright-inspired browser API, and matches the existing modules and release identity. |
| Webwright | Easy to pronounce, but overlaps directly with [Microsoft’s browser-agent project](https://github.com/microsoft/Webwright) and an existing [PyPI package](https://pypi.org/project/webwright/). |
| Kotlinwright | More readable to people unfamiliar with KMP, but longer and does not immediately communicate multiplatform scope. |
| Krosswright | More brand-like, but requires explaining both Kotlin and the product; weaker search intent. |

Exact-name web searches on 2026-10-11 did not surface a competing indexed browser project for Kmpwright, Kotlinwright, or Krosswright. Search absence is not proof of availability. This recommendation is product judgment, not a claim of trademark clearance or user preference testing.

Suggested description: **“Browser automation for Kotlin Multiplatform.”**
Use “Playwright-inspired API” in explanatory copy; native WebViews have different capabilities and Kmpwright is not an official Playwright distribution.
