title: Configuration
description: Every field of KmpwrightConfig and its nested types (TimeoutConfig, DebugConfig, CdpConfig, ProxyConfig, Viewport, IosSchemeInterceptionConfig) and the per-page ActionPolicy, with defaults and what each one actually changes.
---

`KmpwrightConfig` is passed once, when you create a `Browser` (or `launchBrowser`). Every page of that browser uses it.

```kotlin
val config = KmpwrightConfig(
    timeouts = TimeoutConfig(default = 15_000, navigation = 45_000),
    allowedOriginRules = setOf("https://example.com", "https://*.example.com"),
    allowEval = false,
)
val browser = Browser(AndroidPlatformContext(context, webView), config)
```

All types are immutable data classes; use `copy(...)` to derive variants. Source: [KmpwrightConfig.kt](https://github.com/bernaferrari/kmpwright/blob/main/kmpwright-core/src/commonMain/kotlin/com/bernaferrari/kmpwright/core/KmpwrightConfig.kt).

### `allowedOriginRules`

Each rule is either an exact origin (`"https://example.com"`, compared after normalization) or a glob matched against the origin string (`"https://*.example.com"`). With a non-empty set:

- `goto` to any other origin throws `KmpwrightException`: "Navigation origin is not allowed by KmpwrightConfig: url" (`about:blank` is always allowed),
- a navigation that commits to another origin (for example after a redirect or a link click) returns or emits `ok = false` with "Committed navigation origin is not allowed by KmpwrightConfig: url",
- `page.read(url)` and `HttpReader` refuse other origins ("HTTP read origin is not allowed"),
- on Android, init scripts are registered only for these origins.

This is a configuration-time origin allowlist. For agent-browser's `--allowed-domains` host filter that also blocks subresources, use `page.setAllowedDomains(...)` (see [Network](/docs/guides/network)).

### `InstallMode`

| Value | Effect |
|---|---|
| `DocumentStartPreferred` (default) | The runtime is installed on demand. |
| `AlwaysEvaluate` | Same as `DocumentStartPreferred` in the current implementation. |
| `Disabled` | Locators, `getBy*`, snapshots and other APIs that need the runtime throw "Selector helpers are disabled by KmpwrightConfig.installMode". |

### `InputMode`

| Value | Locator actions | `page.touchscreen` | `page.mouse`, `page.keyboard` |
|---|---|---|---|
| `Hybrid` (default) | JVM: native CDP `Input` events. Android/iOS: DOM events from the page runtime. | Available | Available |
| `TouchOnly` | JVM: clicks become CDP touch taps; other actions use DOM events. Android/iOS: DOM events. | Available | Throw `KmpwrightUnsupportedException` ("Native mouse requires InputMode.Hybrid" / "Native keyboard requires InputMode.Hybrid") |
| `JsOnly` | DOM events from the page runtime on every backend. | Throws "Native touch is disabled by InputMode.JsOnly" | Throw (as above) |

## `TimeoutConfig`

Every `timeoutMs: Long? = null` parameter in the API resolves against these values. A timeout that expires throws `KmpwrightTimeoutException` (assertions throw `KmpwrightAssertionError`).

    navigation: { type: 'Long', description: 'goto, reload, goBack, goForward, setContent, waitForNavigation, waitForURL, waitForLoadState, pushState.', default: '30_000' },
    action: { type: 'Long', description: 'Locator actions (click, fill, press, check…) and native input (page.mouse, page.keyboard, page.touchscreen).', default: '30_000' },
    waitForSelector: { type: 'Long', description: 'expect(locator) and expect(page) assertions, locator.waitFor, page.waitForSelector, and the attach wait of selector queries such as page.textContent(selector).', default: '30_000' },
    handler: { type: 'Long', description: 'Bounds your callbacks that block the page, on every backend: an onDialog handler that does not answer in time dismisses the dialog, and a route handler that does not decide in time aborts the request with error code timedout.   }}
/>

```kotlin
// Fail fast in tests, allow slow page loads.
KmpwrightConfig(timeouts = TimeoutConfig(default = 5_000, action = 5_000, waitForSelector = 5_000, navigation = 60_000))
```

Playwright: `page.setDefaultTimeout` / `setDefaultNavigationTimeout` are per page and mutable. KMPwright sets the defaults once per `Browser`, has a separate bucket for assertions, and bounds dialog and route handlers (`handler`), which Playwright does not.

## `ProxyConfig`

JVM only. KMPwright uses `host` and `port` as the HTTP proxy for its own WebSocket connection to the CDP endpoint (useful when a cloud provider is only reachable through a proxy). It does not configure the browser's proxy; pass `--proxy-server=…` in `BrowserLaunchOptions.arguments` for that.

<TypeTable
  type={{

    bypass: { type: 'List<String>', description: 'Not used by the current implementation.', default: 'emptyList()' },
    username: { type: 'String?', description: 'Not used by the current implementation.', default: 'null' },

Derived properties: `host` (the URL's host), `port` (default 8080), `scheme` (default `"http"`). `toString()` masks the password and credentials embedded in the URL.

## `ActionPolicy`

Not part of `KmpwrightConfig`: an action policy is set per page with `page.setActionPolicy(policy)`, like agent-browser's `--action-policy`. Every page action checks it first.

```kotlin
page.setActionPolicy(ActionPolicy(
    deniedActions = setOf(ActionType.Evaluate),
    confirmActions = setOf(ActionType.Navigate),
    allowedDomains = setOf("example.com"),
))
page.setPolicyConfirmCallback { action, url -> askUser("Allow $action on $url?") }
```

<TypeTable
  type={{
    defaultAction: { type: 'PolicyResult', description: 'Decision when no other rule applies: Allow, Deny or Confirm.', default: 'PolicyResult.Allow' },
    allowedActions: { type: 'Set<ActionType>', description: 'When non-empty, every other action is denied.', default: 'emptySet()' },
    deniedActions: { type: 'Set<ActionType>', description: 'Always denied.', default: 'emptySet()' },
    confirmActions: { type: 'Set<ActionType>', description: 'Require the confirm callback to return true.', default: 'emptySet()' },
    allowedDomains: { type: 'Set<String>', description: 'When non-empty, actions on other hosts are denied. A domain matches itself and its subdomains.', default: 'emptySet()' },
    deniedDomains: { type: 'Set<String>', description: 'Actions on these hosts and their subdomains are denied.', default: 'emptySet()' },
  }}
/>

`policy.check(action, url)` evaluates the rules in this order: when any domain list is set and the URL has no http(s) host, Deny; denied domains; allowed domains; denied actions; confirm actions; allowed actions; `defaultAction`.

`ActionType` values: `Click`, `Type`, `Press`, `Navigate`, `Fill`, `Screenshot`, `Evaluate`, `Scroll`, `Drag`, `Hover`, `SetCookie`, `DeleteCookie`, `SetContent`, `AddScriptTag`, `AddStyleTag`, `Focus`, `Select`, `ReadContent` (HTML, text, snapshots, cookies and storage reads), `Storage` (writing or clearing local/session storage), `Clipboard`, `Network` (request headers, HTTP credentials), `Emulation`.

Failures throw `KmpwrightException`: "Action denied by policy: Click", "Action Navigate requires confirmation but no confirm callback is set", or "Action denied by user confirmation: Navigate".
