description: Complete reference of the Page interface and its public extension functions (selector conveniences, action-scoped waits, dialogs, tabs, agent commands), with every option class and its defaults.

`Page` is one browser tab or WebView, modeled on Playwright's `Page` plus agent-browser's agent features. Get one from `browser.page()`, `browser.newPage()` or `context.newPage()`.

```kotlin
val page = browser.newPage()
page.goto("https://example.com")
page.click("text=More information")             // extension: page.locator(selector).click()
val response = page.waitForResponse("**/api/*") { click("#load") }
expect(page).toHaveTitle(Regex("Example"))
```

Conventions:

- Every operation is `suspend` unless marked otherwise below.
- A `timeoutMs` of `null` uses the matching [`TimeoutConfig`](/docs/reference/configuration#timeoutconfig) default. Timeouts throw `KmpwrightTimeoutException`.
- `Page` extends `ElementFinder`, so it has `locator`, `frameLocator` and every `getBy*` method. They are listed on [Locator](/docs/reference/locator#elementfinder).
- Members marked "CDP only" throw `KmpwrightUnsupportedException` on Android and iOS. See [Capabilities](/docs/platforms/capabilities).
- String URL parameters (`route`, `unroute`, `waitForURL`, `waitForRequest`, `waitForResponse`, `waitForNavigation`, `waitForDownload`, `expect(page).toHaveURL`) use Playwright's URL glob over the **full** URL: `**` matches anything including `/`, `*` anything except `/`, `{a,b}` either alternative, `\` escapes, and every other character (including `?`) is literal. A string without glob characters is an exact URL (`"https://example.com"` equals `https://example.com/`); an empty string matches everything. Use `"**/api/items"` for a path on any host, the `Regex` overloads, or the KMPwright `regex:` prefix where only a String is accepted.

Source: [Page.kt](https://github.com/bernaferrari/kmpwright/blob/main/kmpwright-core/src/commonMain/kotlin/com/bernaferrari/kmpwright/core/Page.kt), [PageConvenience.kt](https://github.com/bernaferrari/kmpwright/blob/main/kmpwright-core/src/commonMain/kotlin/com/bernaferrari/kmpwright/core/PageConvenience.kt), [PageWaits.kt](https://github.com/bernaferrari/kmpwright/blob/main/kmpwright-core/src/commonMain/kotlin/com/bernaferrari/kmpwright/core/PageWaits.kt).

## Navigation

| Member | Description |
|---|---|
| `goto(url: String, options: GotoOptions = GotoOptions()): NavigationResult` | Navigates the main frame and waits for `waitUntil`. A failed or blocked navigation returns `ok = false` with `error`; only a timeout throws. |
| `reload(options: ReloadOptions = ReloadOptions()): NavigationResult` | Reloads and waits for the new document. |
| `goBack(options: HistoryNavigationOptions = HistoryNavigationOptions()): NavigationResult?` | Back in history; null when there is no previous entry. |
| `goForward(options: HistoryNavigationOptions = HistoryNavigationOptions()): NavigationResult?` | Forward in history; null when there is no next entry. |
| `pushState(url: String, timeoutMs: Long? = null): NavigationResult` | Client-side navigation through the Next.js router or `history.pushState` (agent-browser `pushstate`). Needs `allowEval`. |

`NavigationResult(url: String, status: Int, ok: Boolean, error: String? = null)`: `url` is the final URL after redirects; `status` the HTTP status of the final response (200 for local documents such as `setContent`, 0 when the navigation failed); `ok` is Playwright's `response.ok()`: committed **and** status 200..299. A 404 or 500 page is committed with `ok = false` and `error = null`; `error` is set only when no document was committed (network error, policy, domain filter).

## Network

| Member | Description |
|---|---|
| `route(url: String, handler: suspend (Route) -> Unit)` | Intercepts requests matching the URL glob. The handler calls `fulfill`, `abort`, `resume` or `fallback`; returning without a decision falls back. The newest matching route runs first. Registering the same `url` replaces its handler. Returns once interception is active. |
| `route(url: Regex, handler: suspend (Route) -> Unit)` | Intercepts requests whose full URL matches the regex. |
| `unroute(url: String)` | Removes the route registered for that glob. |
| `unroute(url: Regex)` | Removes the route registered for that regex. |
| `unrouteAll()` | Removes every route. |
| `fun onDialog(handler: suspend (DialogEvent) -> DialogResponse): DialogHandler` | Answers JavaScript dialogs; the newest handler wins. `DialogHandler.close()` removes it. A handler that does not answer within `TimeoutConfig.handler` dismisses the dialog. Non-suspending. |
| `setExtraHTTPHeaders(headers: Map<String, String>)` | Sends `headers` with every request. Android and iOS only accept an empty map. |
| `setHTTPCredentials(credentials: HttpCredentials?)` | Answers HTTP authentication with `HttpCredentials(username, password)`; null clears. |
| `setFileChooserInterception(enabled: Boolean = true)` | Enables native file chooser interception. CDP only; required before `waitForFileChooser`. |
| `setDownloadPath(path: String)` | Directory where downloads are saved. CDP only. |
| `setDownloadBehavior(behavior: DownloadBehavior)` | `SaveToDownloadPath`, `Deny` or `Allow`. CDP only. |

`Route` has `request: Request` and `fulfill(status = 200, headers = emptyMap(), body = null, bodyBytes = null, contentType = null, json = null)` (`json` is an already-serialized body that cannot be combined with `body`/`bodyBytes`; `bodyBytes` wins over `body`), `abort(errorCode = "failed")`, `resume(url = null, method = null, headers = null, postData = null)` (Playwright `route.continue()`) and `fallback()`. A handler decides once; a second decision throws "Route is already handled". Handlers are bounded by `TimeoutConfig.handler`. See [Network](/docs/guides/network).

## Dialog helpers (extensions)

| Extension | Description |
|---|---|
| `fun Page.acceptDialogs(): DialogHandler` | Accepts every dialog until the handle is closed. |
| `fun Page.dismissDialogs(): DialogHandler` | Dismisses every dialog until the handle is closed. |
| `fun Page.acceptDialogsIf(predicate: (DialogEvent) -> Boolean): DialogHandler` | Accepts matching dialogs and dismisses the rest. |
| `suspend fun Page.waitForDialog(timeoutMs: Long? = null): DialogEvent` | The next dialog (Playwright `waitForEvent('dialog')`). While waiting it counts as a dialog listener, so dialogs reach automation even on Android. It is answered by the newest `onDialog` handler, or dismissed. |

`DialogEvent(type: DialogType, message: String, defaultPrompt: String? = null)` with `DialogType` `Alert`, `Confirm`, `Prompt`, `BeforeUnload`. `DialogResponse` is `Accept`, `Dismiss` or `Text(text)` (accepts a prompt with `text`). Without a handler, dialogs are dismissed on iOS and JVM and left to the WebView's own UI on Android.

## Tabs and lifecycle

| Member | Description |
|---|---|
| `openNewTab(url: String? = null): NavigationResult` | Opens a new page that inherits this page's routes and emulation and navigates it to `url` (`about:blank` when null). |
| `close()` | Closes the page and waits for its resources to be released. Idempotent. Playwright: `page.close()`. |
| `fun dispose()` | Non-suspending, best-effort teardown for lifecycle callbacks (Compose `onDispose`, `Activity.onDestroy`). Returns immediately; prefer `close()`. |

After `close()`, page operations throw `KmpwrightException`: "Page is closed".

Browser extensions for tabs (agent-browser `tab`): `fun Browser.tabList(): List<TabInfo(index, url, page)>`, `fun Browser.switchToTab(index: Int): Page`, `suspend fun Browser.closeTab(index: Int)`. Out-of-range indexes throw "Tab index N out of range (0..M)". Also `suspend fun Browser.use(url: String, block: suspend Page.() -> Unit)` (new page, navigate, run, close) and `suspend fun Browser.use(block: suspend Page.() -> Unit)` (runs on the default page without closing it).

Hot, non-replaying `SharedFlow`s. Subscribe before triggering the action, or use the action-scoped waits.

| Property | Type |
|---|---|
| `console` | `SharedFlow<ConsoleMessage>` (`type`, `text`, `location: SourceLocation?`) |
| `navigation` | `SharedFlow<NavigationEvent>` (`url`, `status`, `navigationType`: `SameDocument` or `NewDocument`) |
| `loadState` | `SharedFlow<LoadState>` |
| `dialog` | `SharedFlow<DialogEvent>` |
| `request` | `SharedFlow<Request>` |
| `response` | `SharedFlow<Response>` (failed requests: status 0, error in `statusText`) |
| `download` | `SharedFlow<Download>` |
| `fileChooser` | `SharedFlow<FileChooser>` |
| `pageError` | `SharedFlow<PageError>`: uncaught exceptions and unhandled promise rejections (Playwright `pageerror`) |

Collecting `dialog` does not register a dialog listener: on Android a dialog is only emitted while an `onDialog` handler or a `waitForDialog` is active.

`PageError(name, message, stack: String? = null, location: SourceLocation? = null)` has `text` (`"Name: message"`, or the message when `name` is empty). `ConsoleMessage.type` is one of Playwright's values: `log`, `debug`, `info`, `error`, `warning`, `dir`, `dirxml`, `table`, `trace`, `clear`, `startGroup`, `startGroupCollapsed`, `endGroup`, `assert`, `profile`, `profileEnd`, `count`, `timeEnd`. `PageMessageFilter` is `SinceNavigation` or `All`.

`Download` has `url`, `suggestedFilename`, `path(): String?` and `saveAs(path)` (throws when no download path was set). `FileChooser` has `isMultiple` and `setFiles(files)` (an empty list cancels).
